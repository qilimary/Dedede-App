# 纠错 Pro（Dedede-App）

**一个认真对待中文表达的本地纠错工具。**

写东西的时候，难免会把“的、地、得”用混，把“做、作”写错，或者一不小心多敲一个字。有些错误很明显，有些却藏在一句读起来还算通顺的话里。

**纠错 Pro** 想做的，就是帮你把这些问题找出来，同时尽量保留原来的表达。它不是替你重新写一篇文章，而是让你写好的文字更准确、更顺畅。无论是聊天、日常记录，还是较长的文章，都可以拿来检查。

项目由 **奇** 开发，所用中文纠错模型也由奇训练。软件免费使用，主要在设备本地完成文字处理，不需要把正文上传给在线大模型。

[项目仓库](https://github.com/qilimary/Dedede-App) · [构建与下载](https://github.com/qilimary/Dedede-App/actions) · [反馈问题](https://github.com/qilimary/Dedede-App/issues)

## 它能做什么？

### 不只是检查“的地得”

最初容易让人头疼的，往往是那些读音相近、用法却不同的字。比如“认真地写字”“跑得很快”，只看单个字并不能判断对错，还得看前后文。

纠错 Pro 的专业模式会结合上下文检查 **“的、地、得、做、作”**，同时配合内置错词库和规则，处理常见错别字、部分固定搭配以及一些容易遗漏的文字问题。

### 发现多字、成语等细小错误

除了写错字，打字时还可能重复输入，例如把“画蛇添足”写成“画蛇添足足”。项目加入了重复字检查，并为成语建立了独立词库，能够识别部分成语错字和特定语境下的缺字、字序问题。

它也会尽量避开原本就正确的重复表达和完整成语，不会为了修改而修改。

### 两种模式，按需要选择

| 模式 | 适合什么时候用 | 工作方式 |
| --- | --- | --- |
| **专业模式** | 检查文章、作业或想认真校对一段文字时 | 调用本地 HCAM 中文纠错模型，并结合词库、规则和白名单 |
| **极速模式** | 想快速排查常见错字或简单输入问题时 | 不运行神经网络模型，直接使用词库和规则 |

专业模式更重视上下文判断；极速模式更轻巧。你可以根据文字的长度和检查需求切换，而不必每次都使用同一种方式。

### 改不改，由你决定

纠错结果不是只能照单全收。你可以查看改动、还原原字、手动调整结果，也可以把不希望再次被修改的词语加入**白名单**。项目还支持自定义规则和词库，让习惯用语、人名或特别的表达得到保留。

写作本来就有个人风格，工具应该帮忙，而不是替作者做所有决定。

## 从输入到修改，尽量顺手

纠错 Pro 不只是一个输入框。它围绕“拿到文字—检查—查看改动—继续编辑”设计了完整的使用流程。

- **直接输入或粘贴**：把想检查的文字放进来，选择模式即可开始。
- **文件和图片识字**：根据平台提供文件导入、图片 OCR、截图或剪贴板文字识别，不必每次手动誊写。
- **对照查看结果**：保留原文与修改后的内容，标出改动位置，方便逐项确认。
- **修改与还原**：觉得某处不该改，可以恢复原字；需要更细致调整，也能继续编辑。
- **历史与导出**：保留可回看的纠错记录，并提供复制、保存或导出等功能。

不同平台的界面有所区别，但目标是一致的：**让校对成为写作过程中顺手的一步，而不是额外的负担。**

## Android 与 Windows：手机和电脑都能用

### Android：随时随地，想改就改

Android 是项目主要维护的平台之一，适合聊天、日常输入，以及直接在手机上写文章的人。除了主界面的文本纠错，还提供悬浮窗、悬浮球、图片识字、文件导入和历史记录等功能。遇到想检查的文字，既可以粘贴到主界面，也可以用悬浮工具快速纠错，尽量少打断正在做的事。

Android 有两个可以分别安装的版本：

- **普通版**：以蓝色为主的经典界面。
- **兰版**：以浅粉色为主，使用独立图标，功能与普通版保持同一套纠错实现。

两版主要区别在外观与安装身份，你可以选喜欢的，也可以同时保留。

### Windows：更适合认真整理一篇长文

Windows 同样是项目重点维护的平台。它更像一个专门用来校对和修改文字的工作台：原文与修改后内容可以对照查看，改动清单集中展示每一次修改；还有专注编辑、历史记录、查找替换、标点整理和批量处理等工具。不论是短句检查还是文章修改，都能在同一处完成。

可以导入 TXT、Markdown、Word、PowerPoint、文字型 PDF 和图片等内容；也支持截图、剪贴板识字，以及多种文本和对比结果的导出。较长的文字可以一边检查，一边查看正在产生的结果；点击修改记录，还能快速定位到正文中的对应位置。

窗口、字号、主题和一些操作方式都可以调整，希望让认真校对长文这件事更舒服一些。Windows 端也会持续改进编辑体验、纠错结果的呈现方式，以及处理较长文字时的便利性。

### macOS：桌面端的另一种选择

项目也提供 macOS 版本，不过目前主要精力仍放在 **Windows 和 Android** 上。macOS 的不少功能与 Windows 共通，Windows 端的新功能也会逐步移植过去，不单独作为主要维护方向。

## 纠错背后是什么？

纠错 Pro 不是只靠一张“错字替换表”，也不是把整段文字发给聊天机器人重新生成。它把几种不同的方法放在一起：

- **HCAM 本地模型**：从上下文判断“的、地、得、做、作”等容易混淆的用字。
- **内置错词库**：处理能够明确识别的常见错误。
- **语法与文本规则**：辅助检查固定表达、重复输入及部分其他文字问题。
- **成语词库**：识别并保护已有成语，对部分明显错误进行针对性修正。
- **白名单与自定义内容**：让用户保留自己想要的写法。

这些方法各有擅长的地方。模型负责需要理解前后文的判断，词库和规则处理更明确的问题，再把结果交给用户确认。Android 使用 ExecuTorch 在本地运行模型，Windows 使用 ONNX 形式的本地模型；两者不需要云端文本纠错服务。

项目仍在持续完善，目前以 Android 和 Windows 为主要更新方向。这里只简单提一下版本，不把每次界面调整都写成冗长的更新日志。

| 平台 | 当前版本或状态 | 简要介绍 |
| --- | --- | --- |
| Android | **4.1.5-PTE** | 本地模型推理，普通版与兰版双版本，配合悬浮纠错和图片识字等功能 |

近期 Android 与 Windows 也补充了**成语保护、成语错字及重复字检查**等功能，继续丰富模型之外的纠错能力。

## 写在最后

中文有很多微妙的地方。同样一个读音，放在不同句子里可能就该写成不同的字；一句话看上去没什么问题，细读才发现多了一个字。

纠错 Pro 会继续围绕这些真实的小问题改进：**多找到一点错误，少误改一点原文，让检查文字变得更轻松。**

软件并不保证每一处判断都正确，最后仍然以你的表达为准。欢迎通过 [Issues](https://github.com/qilimary/Dedede-App/issues) 交流想法和反馈问题。
