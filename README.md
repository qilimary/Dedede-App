# 纠错 Pro（Dedede-App）

由 **奇** 制作与训练的本地中文纠错工具。当前包含 Android、Windows 和 macOS 构建入口，使用 HCAM 模型、错词库、窄范围语法规则与白名单协同纠错。公众号：**Li的信箱**。

本次更新重点为 **Windows 1.2.4**。Android 和 macOS 源码保持原样，不能将 Windows 的新交互说明视为其他平台已经同步上线。

## 平台与源码

| 平台 | 入口 | 当前情况 |
|---|---|---|
| Windows 10 2004+ / 11 x64 | `dedede-windows.py` | 1.2.4；WPF、.NET 10、HCAM V2 五字 ONNX INT8 模型 |
| Android arm64 | `dedede-build.sh` | 当前构建脚本为 4.1-PTE；ExecuTorch 1.5.1、中文 ML Kit OCR |
| macOS | `dedede-macos.py` | 独立桌面构建入口；本次未修改 |

专业模式检查“的、地、得、做、作”，结合词库与规则；极速模式只运行词库与规则。两种模式都在本机处理文本。客户端模型保护只能提高提取门槛，不代表资源绝对不可提取。

## Windows 1.2.4

| 项目 | 更新后的行为 |
|---|---|
| 默认阈值 | 的 **0.72**、地 **0.72**、得/做/作 **0.75**，温度 **1.0** |
| 实时结果 | 进度、修改清单和已处理的正文一起更新，完成后显示完整全文 |
| 定位 | 清单序号跳转到对应文字，短暂闪烁三次 |
| 正文操作 | 点击彩色改字弹出还原、恢复纠正、改字、加入白名单等选项 |
| 原文编辑 | “清空”行最右端可展开原文；F11 进入原文专注模式 |
| 改后编辑 | “修订标注”旁新增“编辑改后的文”，绿色下划线标注，直接编辑后自动应用 |
| 专注清单 | 右侧窄条展开/收起，可拖动调宽；还原、序号跳转等功能保留 |
| 专注工具 | 撤销、恢复撤销、首行缩进、复制、导出、字号调整 |
| 字数 | 含标点与不含标点同时显示，中间用 `|` 隔开；均不计空白 |
| 界面整理 | 右栏标题改为“修改后”，移除“继续编辑”“保存修订”；开始纠错为浅蓝色 |
| 完全退出后 | 再次启动为空白工作台，历史可手动恢复；不自动恢复上次正文 |

“恢复撤销”是 redo，即重新执行刚撤销的操作；“还原为原字”才是恢复纠错前用字。修改默认立即生效；右侧手动输入框按回车或移开焦点应用，留空表示删除。

改后专注编辑退出时不覆盖左侧原文，复制与导出取得当前修改后全文。直接编辑跨越多条建议时，这些建议合并为可还原的手动修改；其他建议的置信度、位置和状态保留。在此模式再次开始纠错，当前改后文本会成为新一轮原文。

首次升级时，未改动的旧 0.70/0.70 阈值组合自动迁移为 0.72/0.72；其他手动配置保留，可通过“恢复默认设置”使用新默认值。Android 现有阈值仍按其脚本配置，本次未调整。

## 稳定性与性能改进

- 修复鼠标点击后主题色焦点框残留，保留键盘导航的焦点提示。
- 修复专注模式删空不生效、末尾空行丢失、编辑后标注偏移，以及取消时预览与完整结果混淆。
- 流式快照限频、正文增量追加、清单按可见行创建控件；移除超过 2,000 条后不再更新的限制。
- 专注编辑格式刷新防抖，输入法组合期间延后刷新；撤销记录同时限制条数和体积。
- 长图 OCR 同一次识别复用一个 Tesseract 引擎，减少反复加载；取消后不回填结果。
- 规则输入和 Office 文本提取增加长度约束，移除已无入口的独立成稿窗口，功能由改后专注编辑承接。

OCR 仍使用现有 Tesseract LSTM 中文/英文模型。尚无同样本对比证明其他方案在识别率、体积、速度和 Windows 部署便利性上同时更好，因此本次不换引擎、不增加 OCR 依赖。

## 其他保留功能

支持 TXT、MD、DOCX、PPTX、文字型 PDF、图片、剪贴板 OCR、截图识字、拖放、批量处理、查找替换、标点整理、自定义词库及白名单、历史记录、迷你窗口、托盘、全局快捷键、主题与字号调整，以及 TXT/MD/DOCX/HTML 对比报告/CSV 清单导出。

历史最多保留 50 条并限制总文本量，相同原文只保留一条。异常退出草稿可以在设置页手动恢复；正常退出清除工作区草稿。若开启“关闭窗口后留在托盘”，关闭窗口只是隐藏，需从托盘执行退出才算完全退出。

## 替换文件与构建

本次 Windows 替换包的根目录只有两个文件：

| 文件 | 替换到仓库的位置 |
|---|---|
| `dedede-windows.py` | 根目录同名文件，内嵌完整 Windows 源码和资源清单 |
| `README.md` | 根目录同名说明 |
| `windows.yml` | `.github/workflows/windows.yml`，ZIP 中已按此路径放置 |

原仓库其余平台、图标、词库、模型等文件保留。ZIP 是上述完整替换文件的备用包，**不是已经生成的 EXE 安装程序**。无需将展开的 Windows 工程额外提交到根目录。

替换后推送到 `main`，或在 Actions 手动运行 **Windows app**。工作流会还原源码、同步当前安卓规则、下载并校验模型，执行回归、Windows 模型/OCR、安装及界面检查，然后生成 EXE/ZIP 并更新 `windows-latest` 发布。

本地检查与还原：

```bash
python dedede-windows.py --verify-only
python dedede-windows.py
python windows/scripts/sync_android.py --repo .
```

在 Windows PowerShell 中构建：

```powershell
./windows/build.ps1 -Installer
```

构建需要 Python、.NET 10 SDK（`windows/global.json` 指定 10.0.401 系列）、Visual Studio C++ 构建工具及 Inno Setup。安装包自带运行时与模型，最终用户无需自行安装 Python 或 .NET。展开后的 `windows/README.md`、应用内帮助及安装目录的 `使用说明.html` 均已更新。

开发者修改展开后的 C#/XAML，再执行 `python windows/scripts/pack_platform.py`，即可生成新的单文件。原来的 `Dededi-Q10-source.zip` 属于旧 Android 源码归档，本次未删除，也不用于 Windows 构建。

## 本次验证与限制

- Windows WPF 工程在 Linux x64 上交叉编译通过，零警告、零错误。
- 真实 HCAM ONNX 模型参与的核心回归通过 **9,365 项断言**，包括规则、Tokenizer、缓存一致性、可还原编辑等。
- 独立无模型检查通过 **9,338 项断言**，包含大清单流式更新、取消，以及 4,200 次随机编辑的结果一致性和完整还原检查。
- 已扩充 Windows 界面自动检查，覆盖两个专注入口、实时全文、改字还原、启动空白工作台等。
- **本次环境没有运行原生 Windows 窗口、中文输入法、Tesseract DLL 和安装程序。** Windows 工作流及实机验证仍需执行；上述核心断言不是视觉测试或识字准确率评测，不代表已排除所有问题。

单篇最多 30 万 UTF-16 字符。含复杂排版的文档只提取正文，扫描 PDF 应先转图片。模型和 OCR 可能误判，重要内容请复核清单；此版本没有重新训练模型，也不宣称提高了模型准确率。
